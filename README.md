# 留白

为本机 Apple Silicon Mac 编写的轻量护眼工具。技术栈为 Swift 6、AppKit、SwiftUI，无第三方依赖。

## 使用

双击 `dist/留白.app` 启动。0.3.1 只保留一个「智能护眼」开关，自动按护眼宝的时间曲线调整屏幕颜色。当前强度为只读显示，无需手动调节。

- **开启智能护眼**：根据本地时间自动计算强度，通过 Gamma 表调整当前连接屏幕的 RGB 输出。
- **关闭智能护眼**：恢复启用前保存的 Gamma 表。
- **最小化**：点击窗口黄色按钮，或按 `⌘M`。
- **恢复窗口**：点击 Dock 图标，或从菜单栏的眼睛图标选择「打开留白」。应用处于前台时也可按 `⌘0`。
- **关闭窗口**：红色按钮或 `⌘W`；智能护眼继续在后台运行。
- **退出**：菜单栏选择「退出留白」，或在应用处于前台时按 `⌘Q`。正常退出会恢复启用前的 Gamma 表。若系统拒绝恢复，会保留程序并在主窗口显示错误，方便关闭智能护眼后重试。
- **睡眠唤醒**：睡眠前恢复 Gamma，唤醒后按当前时间重新应用。

休息提醒、柔和屏幕总开关、手动强度/调暗、独立夜间助眠功能均已移除。原有手动调暗值和夜间绿色系数不会再参与计算。

首次启动默认关闭。升级自 0.2.0 时，只有原来的「柔和屏幕」和「智能护眼」都开启才继续开启；原来的手动模式不会自动转换为开启状态。后续只记忆新的单开关状态，偏好设置域仍为 `local.liuliang.eyerest`。

## 构建和验证

在本目录运行：

```sh
bash build.sh
bash build.sh --test
```

需要 Apple Silicon Mac、macOS 14 或以上，以及 Apple Command Line Tools。构建目标固定为 `arm64-apple-macos14.0`，产物在 `dist/留白.app`，缓存和测试程序在 `.build/`。使用本地临时签名，适用于本机使用；未配置分发证书和公证。

测试需要可访问当前 macOS 桌面会话。它会临时显示、最小化、关闭和恢复测试窗口，短暂写入真实显示器的 Gamma 表并读回核对，然后恢复原值并退出。测试使用隔离设置，不读写正式应用偏好。

2026-10-10，在本机 macOS 26.7 / arm64 上完成编译及 **63/63 项检查**。本次实机连接了两块屏幕：

- 一天 1440 分钟的强度范围、各时间分段边界、跨午夜切换、本地分钟换算；
- 单开关状态迁移，确认旧手动参数、夜间和提醒设置不会影响新版；
- 模拟两屏读写失败、部分更新回滚、恢复失败重试、断开后重连；
- 两块真实屏幕的当前/午夜 Gamma 写入与读回比对，关闭和退出清理后原值读回比对（容差 0.005）；
- 最小化、菜单栏恢复及精简菜单检查；
- 调用睡眠/唤醒处理验证恢复和重新应用，未让机器实际休眠。

正式 0.3.0 应用已启动并检查截图和辅助功能树，界面只有智能护眼开关和只读强度，没有滑杆或提醒入口；原先已开启的自动护眼状态成功保留。测试日志在 `.build/gamma-verification.log`，不纳入仓库。

## 智能护眼规则

以已分析的护眼宝 1.2.0 时间规则独立实现，未包含其可执行程序或反汇编文件。界面图标来源见下方说明。设 `t = 本地小时 + 分钟 / 60`，强度 `s` 在以下节点之间线性插值：

| 时间 | 强度 |
| --- | --- |
| 00:00 | 0.75 |
| 03:00 | 0.90 |
| 07:00 | 0.30 |
| 12:00 | 0.10 |
| 18:00 | 0.30 |
| 24:00 | 0.75 |

只使用原版智能护眼暖色方案的通道增益，不叠加手动调暗或独立夜间助眠系数：

```text
R = 1 - 0.10 × s
G = 1 - 0.25 × s
B = 1 - 0.50 × s
```

与原版一样，每 30 秒检查当前时间，时间曲线精确到分钟；开启及唤醒时立即计算，仅增益或显示器状态变化时写入。所有计算基于启用前保存的各屏幕 Gamma 表，保留原有曲线形状，避免重复乘算累计变暗。接口为 Apple 的 [CGGetDisplayTransferByTable](https://developer.apple.com/documentation/coregraphics/cggetdisplaytransferbytable(_:_:_:_:_:_:)) 和 [CGSetDisplayTransferByTable](https://developer.apple.com/documentation/coregraphics/cgsetdisplaytransferbytable(_:_:_:_:_:))。

## 实现范围

Gamma 调整影响显示器颜色输出，不修改硬件背光和 Night Shift 设置。不要同时让其他护眼软件或 Night Shift 调整颜色，否则可能叠加或相互覆盖。

不支持 Gamma 读写的屏幕会显示错误；一块屏幕出错时尝试恢复所有已调整且仍连接的屏幕。断开的屏幕保留内存快照，若以相同显示器 ID 重连可继续恢复。物理热插拔、HDR、真实睡眠、显示器 ID 变化、系统升级、长期运行，以及崩溃/强制退出的恢复尚未验证。实机测试验证的是 API 读回值，不是色度计测量。

正常关闭开关或退出可回滚本次颜色变化；强制结束进程会丢失内存快照，不能承诺恢复启用前的颜色。

本程序不请求网络、录屏或辅助功能权限。没有自动更新、开机自启和联网服务，不包含原应用的资讯、动画课程等功能。

构建仅生成本目录下的文件，不替换 `/Applications/护眼宝.app`。停止使用时正常退出留白即可恢复屏幕；需要移除时可在退出后将本项目目录移至废纸篓。
