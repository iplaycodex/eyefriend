# 留白

为本机 Apple Silicon Mac 编写的轻量护眼工具。技术栈为 Swift 6、AppKit、SwiftUI，无第三方依赖。

## 使用

双击 `dist/留白.app` 启动。主窗口的两个开关分别启用屏幕滤镜和休息提醒；首次启动默认关闭，可按需开启。设置会保存到本应用的偏好设置域 `local.liuliang.eyerest`。

- **最小化**：点击窗口黄色按钮，或按 `⌘M`。
- **恢复窗口**：点击 Dock 图标，或点击菜单栏的眼睛图标并选择「打开留白」。应用处于前台时也可按 `⌘0`。
- **关闭窗口**：红色按钮或 `⌘W`；程序继续在后台运行。
- **退出**：菜单栏选择「退出留白」，或在应用处于前台时按 `⌘Q`。退出即移除滤镜并停止提醒。
- **屏幕滤镜**：可调暖色和暗度，覆盖当前连接的屏幕，鼠标点击可穿透。调暗滑杆的 100% 表示本应用的最大调暗强度，不会把屏幕变成全黑。
- **休息提醒**：间隔可选 20/30/45/60 分钟，休息时长可选 20/30/60 秒。提醒以非强制浮窗出现；可以完成或推迟 5 分钟，关闭提醒浮窗也会推迟 5 分钟。点击「现在休息」会同时开启后续周期提醒。
- **睡眠唤醒**：重置为完整的提醒间隔，避免醒来立即显示过期提醒。

## 构建和验证

在本目录运行：

```sh
bash build.sh
bash build.sh --test
```

需要 Apple Silicon Mac、macOS 14 或以上，以及 Apple Command Line Tools。构建目标固定为 `arm64-apple-macos14.0`，产物在 `dist/留白.app`，缓存和测试程序在 `.build/`。使用本地临时签名，适用于本机使用；未配置分发证书和公证。

测试需要可访问当前 macOS 桌面会话。它会临时显示、最小化、关闭和恢复测试窗口，短暂显示滤镜，然后清理并退出。测试使用内存设置，不读写正式应用偏好。

2026-10-10，在本机 macOS 26.7 / arm64 上完成编译及 **29/29 项检查**：

- 提醒时间边界、休息完成、暂停和稍后提醒；
- 真实 NSWindow 黄色按钮和菜单 `⌘M` 响应后，`isMiniaturized` 为真；
- 最小化时可出现提醒，关闭主窗口后程序继续运行，菜单栏能恢复窗口；
- 当前连接屏幕的滤镜窗口数量、鼠标穿透、关闭滤镜和退出清理；

## 实现范围

暖色和调暗是透明窗口的视觉叠加，不修改显示器硬件亮度或系统 Night Shift 色温。它可能影响截图色彩；系统安全界面或部分独占全屏内容不保证覆盖。尚未验证外接屏热插拔、所有全屏应用和长期运行。

本程序不请求网络、录屏或辅助功能权限。没有自动更新、开机自启和联网服务，不包含原应用的资讯、动画课程等功能。

构建仅生成本目录下的文件，不替换 `/Applications/护眼宝.app`。停止使用时退出留白即可恢复屏幕；需要移除时可在退出后将本项目目录移至废纸篓。
