# EyeFriend

为本机 Apple Silicon Mac 编写的轻量护眼工具。技术栈为 Swift 6、AppKit、SwiftUI，无第三方依赖。

当前版本：**0.3.3**。仅支持 **Apple Silicon Mac、macOS 14 及以上**。

## 安装

本机安装包：`dist/EyeFriend-0.3.3-arm64.dmg`。

1. 正常退出正在运行的旧版应用。
2. 打开 DMG，将 **EyeFriend.app** 拖入 **Applications（应用程序）**。
3. 从“应用程序”启动 **EyeFriend**，然后推出磁盘映像。

安装包使用本地临时签名，未做 Apple 公证，供本机个人使用。`dist/` 是本地生成目录，不纳入 Git；克隆仓库后需按下文构建，`bash build.sh` 只生成 `.app`，不会生成 DMG。

应用更名保留原 Bundle Identifier（`local.liuliang.eyerest`）和偏好设置，原有智能护眼开关状态会继续沿用。

## 使用

只保留一个「智能护眼」开关，自动随时间调整屏幕颜色。当前强度为只读显示，无需手动调节。

- **开启智能护眼**：根据本地时间自动计算强度，通过 Gamma 表调整当前连接屏幕的 RGB 输出。
- **关闭智能护眼**：恢复启用前保存的 Gamma 表。
- **最小化**：点击窗口黄色按钮，或按 `⌘M`。
- **恢复窗口**：点击 Dock 图标，或从菜单栏的眼睛图标选择「打开EyeFriend」。应用处于前台时也可按 `⌘0`。
- **关闭窗口**：红色按钮或 `⌘W`；智能护眼继续在后台运行。
- **退出**：菜单栏选择「退出EyeFriend」，或在应用处于前台时按 `⌘Q`。正常退出会恢复启用前的 Gamma 表。若系统拒绝恢复，会保留程序并在主窗口显示错误，方便关闭智能护眼后重试。
- **睡眠唤醒**：睡眠前恢复 Gamma，唤醒后按当前时间重新应用。

休息提醒、柔和屏幕总开关、手动强度/调暗、独立夜间助眠功能均已移除。原有手动调暗值和夜间绿色系数不会再参与计算。

首次启动默认关闭。升级自 0.2.0 时，只有原来的「柔和屏幕」和「智能护眼」都开启才继续开启；原来的手动模式不会自动转换为开启状态。后续只记忆新的单开关状态，偏好设置域仍为 `local.liuliang.eyerest`。

## 智能护眼规则

EyeFriend 根据本地时间计算自动护眼强度。设 `t = 本地小时 + 分钟 / 60`，强度 `s` 在以下节点之间线性插值：

| 时间 | 强度 |
| --- | --- |
| 00:00 | 0.75 |
| 03:00 | 0.90 |
| 07:00 | 0.30 |
| 12:00 | 0.10 |
| 18:00 | 0.30 |
| 24:00 | 0.75 |

智能护眼采用以下 RGB 通道增益，不叠加手动调暗或独立夜间助眠系数：

```text
R = 1 - 0.10 × s
G = 1 - 0.25 × s
B = 1 - 0.50 × s
```

每 30 秒检查当前时间，时间曲线精确到分钟；开启及唤醒时立即计算，仅增益或显示器状态变化时写入。所有计算基于启用前保存的各屏幕 Gamma 表，保留原有曲线形状，避免重复乘算累计变暗。接口为 Apple 的 [CGGetDisplayTransferByTable](https://developer.apple.com/documentation/coregraphics/cggetdisplaytransferbytable(_:_:_:_:_:_:)) 和 [CGSetDisplayTransferByTable](https://developer.apple.com/documentation/coregraphics/cgsetdisplaytransferbytable(_:_:_:_:_:))。

## 实现范围

Gamma 调整影响显示器颜色输出，不修改硬件背光和 Night Shift 设置。不要同时让其他护眼软件或 Night Shift 调整颜色，否则可能叠加或相互覆盖。

不支持 Gamma 读写的屏幕会显示错误；一块屏幕出错时尝试恢复所有已调整且仍连接的屏幕。断开的屏幕保留内存快照，若以相同显示器 ID 重连可继续恢复。物理热插拔、HDR、真实睡眠、显示器 ID 变化、系统升级、长期运行，以及崩溃/强制退出的恢复尚未验证。实机测试验证的是 API 读回值，不是色度计测量。

正常关闭开关或退出可回滚本次颜色变化；强制结束进程会丢失内存快照，不能承诺恢复启用前的颜色。

本程序不请求网络、录屏或辅助功能权限。没有自动更新、开机自启和联网服务。

构建仅生成本目录下的文件。停止使用时正常退出 EyeFriend 即可恢复屏幕。卸载时先退出，再将“应用程序”里的 `EyeFriend.app` 移至废纸篓；源码目录与已安装应用相互独立。
