# 留白

为本机 Apple Silicon Mac 编写的轻量护眼工具。技术栈为 Swift 6、AppKit、SwiftUI，无第三方依赖。

## 使用

双击 `dist/留白.app` 启动。开启「柔和屏幕」后，可以选择手动强度，或启用「智能护眼」「夜间助眠」。休息提醒独立控制；首次启动默认关闭，可按需开启。设置会保存到本应用的偏好设置域 `local.liuliang.eyerest`。

- **最小化**：点击窗口黄色按钮，或按 `⌘M`。
- **恢复窗口**：点击 Dock 图标，或点击菜单栏的眼睛图标并选择「打开留白」。应用处于前台时也可按 `⌘0`。
- **关闭窗口**：红色按钮或 `⌘W`；程序继续在后台运行。
- **退出**：菜单栏选择「退出留白」，或在应用处于前台时按 `⌘Q`。正常退出会恢复启用前的 Gamma 表并停止提醒。若系统拒绝恢复，会保留程序并在主窗口显示错误，方便关闭屏幕调节后重试。
- **屏幕调节**：通过 Gamma 表调整当前连接屏幕的 RGB 输出，不再创建覆盖屏幕的透明窗口。调暗滑杆的 100% 对应额外 50% 通道衰减，不会主动把屏幕调成全黑。
- **智能护眼**：按本地时间计算强度；开启后强度滑杆只读，关闭后回到原先的手动值。
- **夜间助眠**：20:00—08:00 额外调整绿色通道，可与智能或手动模式组合，白天额外系数为 1。
- **关闭屏幕调节**：恢复启用前保存的 Gamma 表，智能/夜间选项保持记忆，休息提醒继续运行。
- **休息提醒**：间隔可选 20/30/45/60 分钟，休息时长可选 20/30/60 秒。提醒以非强制浮窗出现；可以完成或推迟 5 分钟，关闭提醒浮窗也会推迟 5 分钟。点击「现在休息」会同时开启后续周期提醒。
- **睡眠唤醒**：睡眠前恢复 Gamma，唤醒后按当前时间重新应用；同时重置为完整的提醒间隔。

## 构建和验证

在本目录运行：

```sh
bash build.sh
bash build.sh --test
```

需要 Apple Silicon Mac、macOS 14 或以上，以及 Apple Command Line Tools。构建目标固定为 `arm64-apple-macos14.0`，产物在 `dist/留白.app`，缓存和测试程序在 `.build/`。使用本地临时签名，适用于本机使用；未配置分发证书和公证。

测试需要可访问当前 macOS 桌面会话。它会临时显示、最小化、关闭和恢复测试窗口，短暂写入真实显示器的 Gamma 表并读回核对，然后恢复原值并退出。测试使用内存设置，不读写正式应用偏好。

2026-10-10，在本机 macOS 26.7 / arm64 上完成编译及 **79/79 项检查**。本次实机连接了两块屏幕：

- 一天 1440 分钟的强度范围、各时间分段边界、跨午夜切换、本地分钟换算；
- 智能与手动切换、夜间助眠与调暗的组合；
- 模拟两屏读写失败、部分更新回滚、恢复失败重试、断开后重连；
- 两块真实屏幕的普通/午夜 Gamma 写入与读回比对，关闭和退出清理后原值读回比对（容差 0.005）；
- 最小化、菜单栏恢复、后台休息提醒回归；
- 调用睡眠/唤醒处理验证恢复和重新应用，未让机器实际休眠。

正式 0.2.0 应用已启动并检查界面；智能模式能显示当前时间计算的强度并禁用手动强度滑杆。测试日志生成在 `.build/gamma-verification.log`，不纳入仓库。

## 智能护眼规则

以已分析的护眼宝 1.2.0 时间规则独立实现，未包含其二进制、资源或反汇编文件。设 `t = 本地小时 + 分钟 / 60`，强度 `s` 在以下节点之间线性插值：

| 时间 | 强度 |
| --- | --- |
| 00:00 | 0.75 |
| 03:00 | 0.90 |
| 07:00 | 0.30 |
| 12:00 | 0.10 |
| 18:00 | 0.30 |
| 24:00 | 0.75 |

夜间绿色系数 `n`：20:00—24:00 从 1 降至 0.8；00:00—04:00 保持 0.8；04:00—08:00 升至 1；其余时间为 1。未开启夜间助眠时始终为 1。

设调暗值为 `d`（0…1），最终通道增益：

```text
brightness = 1 - 0.5 × d
R = (1 - 0.10 × s) × brightness
G = (1 - 0.25 × s) × brightness × n
B = (1 - 0.50 × s) × brightness
```

每秒检查当前状态，时间曲线精确到分钟；仅增益或显示器状态变化时写入。所有计算基于启用前保存的各屏幕 Gamma 表，保留原有曲线形状，避免重复乘算累计变暗。接口为 Apple 的 [CGGetDisplayTransferByTable](https://developer.apple.com/documentation/coregraphics/cggetdisplaytransferbytable(_:_:_:_:_:_:)) 和 [CGSetDisplayTransferByTable](https://developer.apple.com/documentation/coregraphics/cgsetdisplaytransferbytable(_:_:_:_:_:))。

## 实现范围

Gamma 调整影响显示器颜色输出，不修改硬件背光和 Night Shift 设置。不要同时让其他护眼软件或 Night Shift 调整颜色，否则可能叠加或相互覆盖。

不支持 Gamma 读写的屏幕会显示错误；一块屏幕出错时尝试恢复所有已调整且仍连接的屏幕。断开的屏幕保留内存快照，若以相同显示器 ID 重连可继续恢复。物理热插拔、HDR、真实睡眠、显示器 ID 变化、系统升级、长期运行，以及崩溃/强制退出的恢复尚未验证。实机测试验证的是 API 读回值，不是色度计测量。

正常关闭开关或退出可回滚本次颜色变化；强制结束进程会丢失内存快照，不能承诺恢复启用前的颜色。

本程序不请求网络、录屏或辅助功能权限。没有自动更新、开机自启和联网服务，不包含原应用的资讯、动画课程等功能。

构建仅生成本目录下的文件，不替换 `/Applications/护眼宝.app`。停止使用时正常退出留白即可恢复屏幕；需要移除时可在退出后将本项目目录移至废纸篓。
